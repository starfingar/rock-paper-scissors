# Pedra, Papel e Tesoura

Projeto desenvolvido como parte do currículo do The Odin Project (Foundations). 

O objetivo principal deste projeto é praticar a lógica de programação em JavaScript (manipulação de variáveis, funções, estruturas condicionais e laços de repetição), mantendo a execução focada no console do navegador.

## Como executar

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Abra as Ferramentas do Desenvolvedor do navegador (`F12` no computador ou inspecionar elemento no navegador mobile) e acesse a aba Console.
4. Clique no botão "Iniciar Jogo" na página para dar início à partida de 5 rodadas.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript.
